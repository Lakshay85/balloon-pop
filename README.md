# Balloon Pop — Website

Official website for the Balloon Pop game, hosted with GitHub Pages.

## Pages
- `index.html` — landing page (features, screenshots, how to play)
- `privacy-policy.html` — Privacy Policy (use this URL in the Play Store listing)
- `terms.html` — Terms & Conditions
- `style.css` — shared stylesheet
- `assets/` — icon, feature graphic and screenshots

## Hosting (GitHub Pages)
1. Push this folder to a GitHub repository (e.g. `balloon-pop`).
2. In the repo: Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
3. The site will be live at `https://<username>.github.io/balloon-pop/`
4. Privacy policy URL for Play Console: `https://<username>.github.io/balloon-pop/privacy-policy.html`
5. Terms URL: `https://<username>.github.io/balloon-pop/terms.html`

## App
- Package: `com.midnighttales.balloonpop`, version 1.0 (versionCode 1)
- Targets Android 16 (API 36), minSdk 24
